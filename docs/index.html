Uma linha faz a diferença

O quicksort puro e o híbrido são iguais, exceto pela primeira condição. Quando o pedaço tem menos que corte elementos, ele vai para a inserção e a recursão para ali.

Com corte 1, essa condição só vale para a lista vazia. Por isso corte 1 se comporta exatamente como o puro.

def quicksort_hibrido(v, corte):
    if len(v) < corte:
        return insercao(v)   # pedaço pequeno
    if len(v) <= 1:
        return list(v)
    pivo = random.choice(v)
    menores = [x for x in v if x < pivo]
    iguais  = [x for x in v if x == pivo]
    maiores = [x for x in v if x > pivo]
    return (quicksort_hibrido(menores, corte)
            + iguais
            + quicksort_hibrido(maiores, corte))
